# Om mig-sida

Detta är min "Om mig" sida som jag har utvecklat för att nå kursmlen i Bootcamp.

## Innehåll

- Semantisk HTML med header, main, section och footer
- Responsiv layout för mobil och desktop
- Theme toggle som byter mellan mörkt och ljust läge
- Exempel på styrkekort som renderas från JavaScript
- Länkar till LinkedIn och GitHub

### Interaktioner

- Tema växlar via en knapp med addEventListener och sparas i localstorage för att komma ihåg användarens tema prefferens
- Länkar som aktivt stylats som knappar för att kunna användas som effektiva CTA.
- Länkarna i menyn riktas mot element och dess ID istället för att navigera mot separata sidor. Jag gjorde på detta vis för att innehållet inte är tillräckligt omfattande för att få egna sidor.

### Tillgänglighet

- Bilder har alt-text som beskriver dess innehåll för användare som inte har möjlighet att se innehållet.
- Semantiska HTML-element används där det behövs
- Knapp och länkar är tydligt märkta
- Färgtemat är anpassat för att möta krav på kontrast
